# 故障排查

按"你看到的现象"查。找不到就去 `设置 → 关于 → 导出诊断包`。

---

## 安装类

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 蓝色框「Windows 已保护你的电脑」 | SmartScreen 拦了未签名程序 | 点「更多信息」→「仍要运行」 |
| 「此应用已被智能应用控制阻止」 | Win11 智能应用控制（SAC） | 改用便携版 ZIP；或关掉 SAC（不可逆） |
| 杀软报毒 | 未签名程序被误报 | 加白名单 / 从隔离区恢复 |
| 双击没反应 | 首次初始化慢，或被杀软拦了 | 等 30 秒 → 查隔离区 → 换便携版 |
| 弹了 UAC 要管理员密码 | 拿到的不是当前用户级安装包 | 找作者确认版本 |
| 提示「程序正在运行」装不了 | 上次没真正退出（悬浮小窗在后台） | 关掉主窗口即可彻底退出；或重启电脑再装 |

## 语义搜索 / 智能问答类

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 语义搜索点不动、提示模型未就绪 | 模型文件缺失 | 安装包版是内置的。**便携版**请确认解压完整（文件夹里应有 `models` 相关资源） |
| 移动端没有语义搜索 | 手机上跑不动 22MB 的向量模型 | 预期行为。手机端只有全文搜索 |
| 「查询改写」「智能问答」灰着 | 没配 AI Key | `设置 → AI 解析` 填上 Key。这两个必须靠云端大模型，本地做不了 |
| 填了 Key 还是不行 | Key 无效 / 地址填错 / 桌面版 CSP | 点「测试连接」看具体报错 |
| 桌面版连不上 AI，但浏览器版能连 | 桌面壳的 CSP 白名单 | 已放行任意 HTTPS。若仍失败，导出诊断包给作者 |

## 同步类（这是坑最多的一块）

### GitHub 返回 404

- 仓库名格式必须是 `用户名/仓库名`，**不是**完整网址（不要带 `https://github.com/`）
- 仓库不存在
- 或者：仓库是私有的，而 Token 没有权限 —— **私有仓库没权限时也返回 404**

### 测试连接成功，但同步时报 401

「测试」只做只读请求，**写操作需要更高权限**。

- Fine-grained Token：`Contents` 权限必须选 **Read and write**（默认是 Read-only）
- Classic Token：必须勾 `repo`

### 报错 409（写入冲突）

远端文件的 `sha` 变了（在别处改过），或分支名不对。

- 确认分支填的是 `main`（现在 GitHub 新建仓库默认是 `main`）
- 去 GitHub 网页上删掉仓库里那个 JSON 文件，重新同步一次
- 软件已内置 409 自动重试一次

### 报错 403

通常是权限不足或被限流。检查 Token 权限；等一会儿再试。

### `tags.bulkPut(): ConstraintError`

标签的 `name` 是唯一索引，两台设备给同一个标签生成了不同 id。

- 已修复：导入时会做标签合并。**请用 0.2.0 及以上版本。**
- 若仍出现：升级到最新版再同步

### 同步后出现一堆重复条目

**第一次同步的顺序很重要**：

1. 在**数据多的那台**设备上先同步一次（把数据推上去）
2. 再到另一台设备点「同步」（它会先拉下来再合并）

如果两台各自都录了不少内容再同步，会合并出重复项 ——
去 `设置 → 重复数据清理` 一键去掉。

### 删掉的条目又被"拉回来"了

老版本的 bug：删除操作没有同步到远端，且清空数据时会丢掉同步基线。
**0.2.0 已修复**。若还遇到：确认两端都是 0.2.0+。

### 仓库里文件越来越多？

不会。同步的是**一份**全量快照（默认 `personal-os-snapshot.json`），
每次覆盖写同一个文件。如果你看到一堆文件，那是历史遗留，删掉即可。

### 两台设备会不会互相覆盖？

会，如果你让两个人共用一个仓库。**一个仓库只服务一个人。**

## 数据类

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 找不到数据在哪 | 在系统 AppData 里，肉眼看不到 | `设置 → 数据 → 打开这个文件夹` |
| 换电脑后数据没了 | 数据不随软件走 | 在旧电脑导出 JSON，新电脑 `设置 → 数据 → 从备份恢复`（选「覆盖」） |
| 换电脑后 AI 用不了 | **API Key 不随备份迁移**（刻意的） | 重新填一次 Key |
| 卸载后数据还在 | 卸载只删程序 | 想彻底清除就手动删数据目录 |
| 恢复时想要「合并」还是「覆盖」 | —— | 换电脑/重装 → 覆盖；补数据 → 合并 |
| 网页版换浏览器后数据空了 | 数据跟着浏览器 profile 走 | 用同一个浏览器的同一个用户；别用隐私窗口 |

## 界面类

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 悬浮球不见了 | 被 × 隐藏了 | `设置 → 界面 → 恢复悬浮球`，刷新页面 |
| Alt+Space 没反应 | **0.2.0 起默认关闭了**全局快捷键（会和输入法抢键） | `设置 → 界面 → 开启全局快捷键`，可自定义组合 |
| 全局快捷键注册失败 | 被别的软件占了 | 换一个组合，如 `CmdOrCtrl+Shift+K` |
| 应用内快捷键 | —— | `Ctrl/⌘+K` 搜索，`Alt+N` 新建 |

## 性能类

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 第一次打开慢 | 要初始化本地向量模型 | 正常，之后就快了 |
| OCR 很慢 | tesseract.js 在浏览器里跑，图片越大越慢 | 图片先压缩；或干脆不开 OCR（PDF / Word 抽取是秒级的） |
| 附件很多之后变卡 | 全文索引变大 | `设置 → 重复数据清理`；不必要的附件删掉 |

---

## 还是不行？

1. `设置 → 一键体检` —— 它会逐条告诉你是哪一项没配好
2. `设置 → 关于 → 导出诊断包` —— 把 txt 发给作者
3. 别急着删数据。绝大多数问题都能救回来。
