## 未发布（0.2.x 开发中）

### 新增：图片 OCR 两条路，默认云端优先

- **云端视觉识别**：图片压缩到长边 1600 后，用 OpenAI 兼容的 `image_url` 发给视觉模型转录文字。
  中文截图、课件照片、手写都比本地准，3~10 秒返回。设置里可单独指定「识图模型」
  （DeepSeek 用 `deepseek-flash`，因为 `deepseek-chat` 不支持图片）。
- **识别方式三选一**：自动（云端优先、失败退回本机）／只用云端／只用本机（不联网）。默认「自动」。
- 设置页会直接显示**当前走哪条路**，以及云端为什么不可用（没填 Key / 关了联网 / 没填地址）。
- 一键体检里的 OCR 项同步反映云端与本机两条路的状态。

### 修复

- **手机端识别卡死**：tesseract 在手机上跑大图可能几十秒不出结果，
  万一 worker 被系统杀掉 Promise 永不 settle，界面就永远转圈。
  现在识别前统一缩放到长边 1600（快 2~3 倍），并加了超时（本机 120 秒、云端 45 秒），
  超时会明确报错而不是无限等待。
- **本地 OCR 之前根本用不了**：`public/ocr` 里的语言包从来没被放进产物，
  且 tesseract 默认取 `.traineddata.gz` 而检测函数查 `.traineddata`，两处不一致。
- **模型默认值过时**：`deepseek-chat` / `deepseek-reasoner` 已下线，默认改为 `deepseek-flash`。
- 收集箱卡片现在会显示抽取失败的具体原因（原来只有一句"没能抽出来"，toast 一闪而过）。

### 隐私相关

图片 OCR 默认开启且默认优先走云端，**图片会发给你填的服务商**。
不希望图片离开本机，请把「识别方式」改成「只用本机」。

## 0.2.0 — 2026-10-13（首个可分发版）

面向"发给朋友自己装"做的改造。**首次对外分发，非公开发布。**

### 新增

- **首启向导**：第一次打开会引导你选择「纯离线 / 接 AI / 开同步」，全程可跳过。
- **能力体检**：设置页新增「一键体检」，逐条列出 AI、语义搜索、智能问答、OCR、同步、备份的可用状态；任何不可用的能力都会说明**为什么**并给出修复入口，不再出现"灰掉但没解释"的按钮。
- **数据区**（设置页）：
  - 打开数据目录（直接跳到你的数据存在哪）
  - 一键备份（导出带日期的 JSON）
  - 从备份恢复（可选「合并」或「覆盖」）
  - 自动备份提醒
  - 重复数据清理
  - 清空全部数据（保留同步基线，避免删除"复活"）
- **关于**：版本号、构建号、许可与第三方声明、隐私说明、**导出诊断包**（脱敏）。
- **全局快捷键可关闭**：Alt+Space **默认不再注册**，避免与输入法和其他软件抢键；需要时可在设置里开启。

### 变更

- **应用标识**改为 `com.github.wzsl07.personal-os`。
  ⚠️ **本次升级后数据目录会变，旧数据不会自动跟过来。** 升级前请先在旧版「设置 → 备份」导出 JSON，装完新版再导入。
- **安装包不再需要管理员权限**（当前用户级安装），公司电脑 / 校园机房也能装。
- **Windows 智能应用控制（SAC）与 SmartScreen 会拦截未签名的安装包**，这是预期行为，请看《安装指南》里的处理步骤；另外提供**便携版 ZIP** 作为兜底。
- 语义搜索模型（bge-small-zh）与 OCR 语言包**随安装包内置**，装完即可离线使用，不需要另外下载。
- 内容安全策略（CSP）加固：新增 `object-src 'none'`、`base-uri 'self'`、`form-action 'none'`、`frame-ancestors 'none'`。
  注：`connect-src` 仍允许任意 HTTPS，这是**刻意为之**——否则用户自定义的 AI 服务地址会被桌面壳拦掉。
- 版本号改为单一真相源（`package.json`），构建脚本自动同步到桌面配置、页面「关于」与 CHANGELOG 校验。

### 修复

- 关主窗口时彻底退出进程（此前"快速收录"浮球会让进程留在后台，导致安装/卸载时提示"程序正在运行"）。
- 桌面版无法连接 GitHub（CSP 未放行外发 HTTPS）。
- 同步时删除操作不生效、已删除的条目会被"拉回来"。
- 同步时标签因跨设备 id 不一致导致 `ConstraintError`。
- 首次同步顺序不当时产生重复条目（配套提供重复清理工具）。
- 清空数据后同步基线丢失，导致远端已删除内容重新出现。
