# 安装指南

给第一次拿到这个软件的人。全程 3 分钟，不需要管理员权限。

---

## 0. 先选一个版本

| | 安装包（`…-安装包.exe`） | 便携版（`…-便携版.zip`） |
|---|---|---|
| 怎么用 | 双击 → 一路下一步 | 解压 → 双击 `个人工作台.exe` |
| 要不要管理员 | **不需要** | 不需要 |
| 会不会被拦截 | **可能会被拦截**（见第 3 节） | 一般不会 |
| 装在哪 | `%LOCALAPPDATA%\个人工作台\` | 你解压到哪就在哪 |
| 适合谁 | 大多数人 | 安装包装不上的人 |

**建议先试安装包；装不上再换便携版。**

---

## 1. 系统要求

- Windows 10（1809 以上）或 Windows 11，**64 位**
- 约 300 MB 可用空间
- 首次运行需要联网下载一次 WebView2 运行库（Windows 11 一般已自带，Windows 10 多数也已自带）

---

## 2. 安装步骤（安装包）

1. 双击 `个人工作台-0.2.0-win-x64-安装包.exe`
2. 出现安装界面 → 点「下一步」→「安装」
3. 装完会自动打开。桌面和开始菜单会有「个人工作台」快捷方式

> **不会弹"要允许此应用对你的设备进行更改吗"**（UAC）。
> 这个安装包是当前用户级的，不需要管理员密码 —— 公司电脑、校园机房也能装。
> 如果你**看到了** UAC 弹窗，说明你拿到的不是这个版本，请找作者确认。

---

## 3. ⚠️ 被 Windows 拦下来了怎么办（**最常见的问题**）

因为这个软件**没有买代码签名证书**（个人开发，一年几百到几千块），
Windows 会对"没见过的程序"弹出警告。**这不是病毒，是 Windows 的通用策略。**

按你看到的画面，对号入座：

### 情况 A：蓝色方框，写着「Windows 已保护你的电脑」

> 标题：`Windows 已保护你的电脑`
> 下面有 `Microsoft Defender SmartScreen 阻止了无法识别的应用启动。运行此应用可能使电脑处于危险之中。`

**怎么做：**
1. 点框里的 **「更多信息」**（不是"确定"，"确定"会直接关掉）
2. 展开后底部出现一行 **「仍要运行」**，点它
3. 之后正常安装

### 情况 B：写着「此应用已被智能应用控制阻止」

> 这是 Windows 11 的"智能应用控制（Smart App Control）"，比 SmartScreen 更严格。
> 它**不给"仍要运行"的选项**。

**怎么做（按推荐顺序）：**

1. **改用便携版** —— 解压 ZIP，双击里面的 `个人工作台.exe`。
   大多数情况下这样就能直接跑起来。**推荐先试这个。**
2. 如果便携版也被拦：
   打开 `Windows 安全中心` → `应用和浏览器控制` → `智能应用控制` → 关掉它。
   ⚠️ **关掉后无法再开启（除非重装系统）**，请自己权衡。
3. 还有个折中：`Windows 安全中心` → `应用和浏览器控制` → 最下方的
   `智能应用控制` 里如果有「**仅在评估模式下**」，选它就不会硬性拦截。

### 情况 C：杀毒软件报毒（McAfee / 360 / 火绒…）

这是**误报**。原因同上：没签名的陌生程序。

**怎么做：** 在杀软的提示里选「允许运行」/「添加到白名单」/「信任此文件」。
如果杀软已经把它隔离了，去隔离区找回并恢复。

### 情况 D：双击没反应 / 一闪而过

1. 等 30 秒 —— 第一次运行要初始化 WebView2，可能有点慢
2. 检查杀软隔离区
3. 换便携版试试
4. 还是不行：关掉所有杀软再试一次（临时）

## 4. 第一次打开

会看到一个 4 步的引导：

1. **欢迎** —— 说明数据存在你电脑上
2. **选模式** —— 建议选「纯离线」，立刻能用；想用 AI 或同步再选别的
3. 如果选了 AI / 同步 —— 会让你填 Key / 跳到设置页
4. 完成

**任何一步都能点「跳过」，跳过后随时可以在 `设置 → 一键体检` 里补上。**

---

## 5. 装完之后必做的一件事

**`设置 → 数据 → 一键备份（JSON）`**，把导出的文件存到网盘或 U 盘。

这个软件的数据**只存在你这台电脑上**。硬盘坏了就是真没了，作者救不了你。
养成"每周导一次"的习惯，30 秒的事。

---

## 6. 卸载

`Windows 设置 → 应用 → 已安装的应用` 里找到「个人工作台」→ 卸载。

**卸载不会删除你的数据。** 数据留在：

```
%LOCALAPPDATA%\com.github.wzsl07.personal-os\
```

（在软件里：`设置 → 数据 → 打开这个文件夹`）

想彻底清除：先卸载软件，再手动删掉上面这个文件夹。
想保留数据重装：直接装，装完数据还在。

---

## 7. 出了问题怎么求助

`设置 → 关于 → 导出诊断包` → 会下载一个 txt。

这个 txt **只包含版本号、系统信息和"哪些功能能用"**，
**不含**你的任何日程、笔记、正文、API Key。放心发给作者。

如果问题和数据有关（比如同步出错），再另外用
`设置 → 数据 → 一键备份` 导出 JSON，
**自己先打开看一眼**确认里面没有不想给人看的内容，再发送。

## 常见问题速查

**Q：要联网吗？**
A：装的时候联网一次（下 WebView2），之后全程离线可用。AI 和同步是可选功能，开了才联网。

**Q：我的数据会被作者看到吗？**
A：不会。这个软件没有服务器。详见 `PRIVACY.md`。

**Q：能在手机上用吗？**
A：能，但需要作者给你一个网址（网页版）。手机上的数据和电脑是分开的，
两边都开同步才能互通，同步用的是**你自己**的 GitHub 私有仓库。

**Q：能装几台电脑？**
A：随便几台。但各台的数据是独立的，要互通就各台都配同一个 GitHub 仓库。
**注意：一个仓库只服务一个人**，两个人共用一个仓库会互相覆盖。
