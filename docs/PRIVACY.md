# 隐私说明

最后更新：2026-10-13

## 一句话

**你的数据只存在你自己的设备上，作者看不到，也没有任何一台作者的服务器在接收它。**

## 详细回答

### 1. 我的日程、笔记、附件存在哪？

存在**你自己的电脑里**，具体是浏览器/桌面壳的本地数据库（IndexedDB）：

```
%LOCALAPPDATA%\com.github.wzsl07.personal-os\EBWebView\...
```

（在应用内：**设置 → 数据 → 打开数据目录** 可以直接跳到这个位置。）

作者拿不到，因为这些数据从来没有离开过你的硬盘。

### 2. 应用会往服务器发什么？

默认情况下：**什么都不发。** 全部功能离线可用。

只有当你**主动开启**下面某一项时，才会有网络请求，而且全部发往**你自己指定的地方**：

| 你开启了什么 | 数据发往哪里 | 谁付钱 | 谁能看到 |
|---|---|---|---|
| AI 解析 / 智能问答 | 你填的 API 地址（DeepSeek / OpenAI 兼容 / 本地 Ollama） | 你（用你自己的 Key） | 你和该 AI 服务商 |
| 云 OCR | 你填的 OCR 服务地址（默认不启用，本地 OCR 不联网） | 你 | 你和该服务商 |
| 多设备同步 | **你自己创建的 GitHub 私有仓库** | GitHub 免费额度 | 只有你（私有仓库） |

**我们（作者）在这三件事里都不扮演任何角色** —— 没有中转服务器，没有代理，没有日志。

### 3. 我的 API Key 安全吗？

- 填了之后会用 AES-GCM 加密存在本机数据库里，明文不会直接躺在文件里；
- **但它防的是"被人随手翻文件看到明文"，防不住能读你数据库的本机恶意程序**（这一点不做夸大宣传）；
- 如果你开启了「口令模式」，密钥由你的口令派生，不输入口令就连应用自己也解不开；
- **API Key 不会随备份文件迁移到别的电脑**，换机器后需要重新填写（这是刻意的）。

### 4. 同步会不会让别人看到我的数据？

看你自己的设置：

- 用 **GitHub 私有仓库** → 只有你能看到；
- 用 **公开仓库** → 全世界都能看到。**请务必用私有仓库。**

另外：**一个仓库只服务一个人。** 两个人共用同一个仓库会互相覆盖对方的数据。

### 5. 卸载会删掉我的数据吗？

不会。卸载程序只删应用本体，数据目录会保留。
如果你确实想彻底清除，请手动删除上文提到的那个目录，或先在应用内执行「清空全部数据」。

### 6. 有 telemetry / 埋点 / 崩溃上报吗？

**没有。** 应用里没有任何统计上报代码。
这也意味着：如果你的应用出问题了，作者不会知道，需要你主动反馈并附上「设置 → 关于 → 导出诊断包」生成的文件（诊断包里的敏感字段已脱敏，导出界面会先给你看内容）。

### 7. 怎么把我的数据全部拿走？

**设置 → 数据 → 一键备份**，会导出一个 JSON 文件，包含你全部的条目、笔记、附件文本、标签。
这个文件是明文 JSON（AI Key 除外），你可以自己存、自己看、自己删。
